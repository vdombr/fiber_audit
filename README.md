# FiberAudit

Static and runtime fiber-scheduler compatibility auditor for Ruby/Rails applications.

## Install

```sh
gem install fiber_audit
```

## Quickstart

```sh
fiber-audit static
```

> **Disclaimer:** This is a static-only audit. PASS cannot be granted without runtime coverage.

## Status

**v0.1.0** — static analysis only.

See [ARCHITECTURE.md](ARCHITECTURE.md) for the current implementation boundaries,
target static-analysis pipeline, and future runtime architecture.
